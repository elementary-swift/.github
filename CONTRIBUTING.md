# Contributing

Thank you for your interest in contributing to Elementary!

## Contributing Code

For anything beyond small fixes or obvious improvements, please open an issue or start a discussion first. Agreeing on the approach up front saves everyone time, and unannounced large changes may not be accepted.

By submitting a pull request, you agree to license your contribution under the same open-source license ([Apache 2.0](/LICENSE)) as the rest of the project. You confirm that you have permission to share the work and that it doesn’t infringe on any third-party rights.

As the Elementary ecosystem evolves, maintainers may restructure or relocate code — including contributions — to other open-source repositories within the project to keep things organized and maintainable.

## Use of AI Tools

You're welcome to use AI assistants and agentic tools when contributing. What matters is the result, and that a person stands behind it.

- **You own your contribution.** Whoever opens a pull request is responsible for every line in it. Understand what you submit, review it yourself before asking others to, and be ready to discuss it.
- **Tools are not authors.** Use whatever tools help you, but authorship stays with a human. Don't add `Co-authored-by`, `Generated with`, or similar attributions for AI tools to commits or pull requests.
- **Keep it short.** Write pull requests, issues, and review comments for people. Generated text is fine if it's brief, to the point, and reads naturally. Skip the essays, restated diffs, and filler. If the title says it all, an empty description is fine.
- **Comments explain, they don't narrate.** Code comments and docs shouldn't over-explain the obvious or record how a change came about ("Changed X to Y", "Now uses Z as requested"). Explain *why* where it isn't clear; otherwise let the code speak for itself.

Contributions that don't meet these expectations may be closed without detailed review.

## Contributor Conduct

Contributors are expected to follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).

Thanks for contributing and helping the project grow!
